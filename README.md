# Network-Infrastructure-Simulation

This repository contains network simulations I created using Cisco Packet Tracer. The objective was to apply theoretical concepts of network configuration and troubleshooting in a simulated environment.

## Key Configurations:
- Designed network topologies involving multiple subnets.
- Implemented VLANs to segment traffic and improve network security.
- Configured switches and routers to establish internal and external connectivity.
- Applied routing protocols to ensure efficient data pathing.

## Note:
I have included a screenshot showing the final network topology and the connectivity tests (ping results) so you can get a good overview without needing to open the `.pkt` file directly.

To explore the simulations, you will need Cisco Packet Tracer installed on your machine.
